FocusList — Modern Task Management Dashboard
FocusList is a high-performance, frontend-only task management dashboard built for the 1-hour FocusList Challenge. Inspired by modern productivity suites like Linear, Notion, and Raycast, FocusList combines aesthetic design (soft lilac/lavender dark mode aesthetics) with power-user productivity tools like a Command Palette, Pomodoro Timer, Kanban Board, and Subtask breakdowns.

Key Features
Core Task Management & Data Persistence
Full CRUD Support: Create, view, edit, and delete tasks instantly.

Priority System: High (Rose/Red), Medium (Amber), and Low (Emerald) color-coded badges.

Local Storage Integration: All tasks, subtasks, notes, and Pomodoro configurations persist across page refreshes.

Interactive Subtasks: Breakdown complex tasks into checklists with dynamic progress bars.

Confetti Celebrations: Canvas confetti explosion effect upon completing a task.

Multi-View Interface
Grid View: Modern glassmorphism card layout with quick actions.

List View: Dense, structured view optimized for high-volume task scanning.

Kanban Board: Three-column workflow status pipeline (To Do, In Progress, Completed).

Search, Filtering & Bulk Operations
Real-Time Search: Search tasks instantly by title or description.

Multi-Filter Tabs: Filter by status (All, Active, Completed) and priority (High, Medium, Low).

Sorting Options: Sort tasks by Newest, Oldest, Priority, or Due Date.

Bulk Action Toolbar: Select multiple tasks to complete or delete them simultaneously.

Focus & Productivity Utilities
Command Palette (Cmd/Ctrl + K): Raycast-style modal for quick navigation, search, and action execution.

Integrated Pomodoro Timer: Custom 25-minute focus timer with Tone.js synthetic audio chime on completion.

Quick Scratchpad: Instant note pad for unorganized thoughts and temporary reminders.

Data Backup & Restore: Export task data as JSON or import existing JSON files.

Technical Stack
HTML5 & CSS3: Native semantically structured HTML5 and custom CSS CSS-variables styling.

Tailwind CSS (v3 CDN): Utility-first framework for visual styling, responsive design, and animations.

Vanilla JavaScript (ES6+): Zero framework dependencies, pure modern JS state management and event listeners.

External Libraries (via CDN):

FontAwesome 6.4.0: Modern UI icon set.

Tone.js: Synthesizer audio engine for focus timer alerts.

Canvas Confetti: Lightweight particle animation on task completion.
